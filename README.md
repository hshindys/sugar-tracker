# Sugar Tracker

Track daily sugar intake from the QS Bar or a screen-edge popout.

## Features
- Quick add: Sugar (white), Brown sugar, Stevia, Teaspoon sugar
- Desserts: Bonbon, Biscuit, Chocolate bar, Gum
- Sugar equivalents calculator
- Daily sweetener goal tracking
- Today's log with clear/undo

## Installation
```bash
ryoku plugin add https://github.com/hshindys/sugar-tracker --bar
```
